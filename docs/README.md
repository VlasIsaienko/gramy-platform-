# graMY Platform — инструкция для запуска (для НЕ-программиста)

Это не просто демо-страница, а начало настоящего веб-продукта.
Дальше всё будет дополняться, но уже сейчас можно: открыть проект у себя,
залить его на GitHub и опубликовать в интернете через Vercel.

Делай шаги строго по порядку. Не пропускай.

---

## Что внутри архива

```
gramy-platform/
├── frontend/      ← сам сайт (Next.js)
├── database/      ← схема базы данных (для Supabase)
└── docs/          ← вот эта инструкция
```

---

## Шаг 1. Установи Node.js

Это программа, без которой сайт не запустится у тебя на компьютере.

1. Зайди на https://nodejs.org
2. Скачай версию **LTS** (рекомендованную)
3. Установи как обычную программу (просто next → next → finish)
4. Проверь, что всё установилось: открой "Терминал" (на Mac) или
   "Командную строку" / PowerShell (на Windows) и впиши:

```bash
node -v
```

Если в ответ показалась версия (например `v20.14.0`) — всё хорошо, идём дальше.

---

## Шаг 2. Распакуй архив

Распакуй `gramy-platform.zip` в любое удобное место, например на Рабочий стол.

---

## Шаг 3. Установи зависимости проекта

1. Открой Терминал / Командную строку
2. Перейди в папку `frontend` внутри проекта. Например (Mac):

```bash
cd Desktop/gramy-platform/frontend
```

(Windows — то же самое, просто через `cd`)

3. Впиши команду:

```bash
npm install
```

Подожди 1–3 минуты. Это скачает все нужные библиотеки (Next.js, Tailwind и т.д.)
— именно поэтому компьютеру нужен интернет на этом шаге.

---

## Шаг 4. Запусти сайт у себя на компьютере (проверка)

В том же терминале:

```bash
npm run dev
```

Открой браузер и перейди по адресу:

```
http://localhost:3000
```

Ты должен увидеть страницу graMY с двумя кнопками:
**«Я организатор / клуб»** и **«Я игрок»**.

Если видишь — поздравляю, всё работает локально. Чтобы остановить — в терминале
нажми `Ctrl + C`.

---

## Шаг 5. Создай базу данных в Supabase

Supabase — это бесплатный (на старте) сервис базы данных + логина пользователей.

1. Зайди на https://supabase.com → Sign up
2. Нажми **New Project**
3. Название: `gramy-platform-db`
4. Задай пароль базы данных (сохрани его в надёжном месте!)
5. Регион — выбери ближайший (например Frankfurt / EU Central)
6. Подожди 1–2 минуты, пока проект создастся

### Теперь создай таблицы:

1. В левом меню выбери **SQL Editor**
2. Нажми **New query**
3. Открой файл `database/schema.sql` из архива (любым текстовым редактором)
4. Скопируй **весь** текст и вставь в окно SQL Editor в Supabase
5. Нажми **Run**

Если внизу появилось "Success" — таблицы созданы. Можешь зайти в **Table Editor**
и увидеть список: `clubs`, `players`, `tournaments`, `matches` и т.д.

### Возьми ключи доступа:

1. В левом меню: **Project Settings** → **API**
2. Скопируй:
   - **Project URL**
   - **anon public key**

## Шаг 6. Подключи ключи к проекту

1. В папке `frontend` найди файл `.env.local.example`
2. Сделай его копию и переименуй в `.env.local` (без `.example`)
3. Открой `.env.local` текстовым редактором и вставь свои значения:

```
NEXT_PUBLIC_SUPABASE_URL=https://твой-проект.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=твой_длинный_ключ
```

4. Сохрани файл. Перезапусти `npm run dev`, если он был запущен.

⚠️ Файл `.env.local` никогда не попадёт на GitHub — он специально исключён
(см. файл `.gitignore`), потому что в нём секретные ключи.

## Шаг 7. Залей проект на GitHub

Самый простой способ для не-программиста — программа **GitHub Desktop**.

1. Зайди на https://desktop.github.com и установи программу
2. Зайди на https://github.com → создай аккаунт, если нет
3. В GitHub Desktop: **File → Add Local Repository** → выбери папку
   `gramy-platform` (ту, что ты распаковал)
4. Если попросит "создать репозиторий здесь" — соглашайся
5. Внизу слева впиши краткое описание изменений, например
   `Первая версия платформы`
6. Нажми **Commit to main**
7. Нажми **Publish repository** (наверху)
8. Название репозитория: `gramy-platform`
9. ⚠️ Сними галочку "Keep this code private", если хочешь показывать инвестору
   публично, либо оставь приватным — на твой выбор
10. Нажми **Publish Repository**

Готово — проект теперь на твоём GitHub.

## Шаг 8. Опубликуй сайт через Vercel

1. Зайди на https://vercel.com → Sign up (можно через GitHub-аккаунт — удобнее)
2. Нажми **Add New → Project**
3. Найди репозиторий `gramy-platform` и нажми **Import**
4. **Важно:** в поле **Root Directory** укажи `frontend`
   (потому что сам сайт лежит не в корне репозитория, а в папке frontend)
5. Раздел **Environment Variables** — добавь те же два значения, что были в
   `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
6. Нажми **Deploy**
7. Подожди 1–2 минуты — Vercel выдаст тебе ссылку вида
   `gramy-platform.vercel.app`

Это и есть твой настоящий публичный адрес для демо клубам и инвестору.
